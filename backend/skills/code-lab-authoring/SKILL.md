# 代码示例生成法（沙箱内真实执行）

## 硬约束

1. 单文件、可直接执行、必须向 stdout 打印可读结果。
2. 服从当前执行沙箱白名单：不允许 import、不允许文件/网络/系统调用；只用基础语法与内置函数。
3. 不超过 30 行；每个概念只示范一次，不堆砌。
4. 用户给的原始需求措辞优先于示例的「典型性」。

## 教学结构

- 代码自顶向下读：先数据、后转换、再输出；变量名用领域词（不用 a/b/x）。
- 代码后跟一段不超过两句话的中文解释：第一句说这段代码演示了什么规则，第二句指出最容易看错的一行。
- 若主题常见误解存在，在解释中用「注意：」指出，但不要展开成小作文。

## 输出格式

一个 ```python 代码块，随后最多两行中文解释。不要标题、不要列表、不要多余空行。
