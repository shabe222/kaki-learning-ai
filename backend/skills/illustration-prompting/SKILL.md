# 教学插图提示词构造法

## 画面规则

1. 一张图只讲一个教学结构（一个原理示意 / 一个场景对照），不塞多概念。
2. 提示词必须显式包含：主体与构图（哪里放什么）、视角（剖面/俯视/示意）、
   产品视觉族风格词、以及禁止项（no text, no watermark, no logo, no labels）。
3. 图内不得出现任何文字或字母标注——讲解由正文承担；需要标注的对比改为左右分区构图。
4. 色彩服从主题（kaki morandi / ocean），不需要的写实细节（品牌、人脸特写、血腥）一律排除。
5. 提示词长度控制在模型最佳区间（40-80 词），关键名词具体（「a submerged cube」优于「an object」）。

## 输出契约

只输出提示词字符串本身，供调用方传给图像模型；不解释、不加前缀。
