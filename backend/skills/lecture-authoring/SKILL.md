# 学习讲义生成法

## 结构契约（Markdown）

1. `# 标题` 用知识点本名，不加「浅谈」「一文读懂」。
2. `## 核心内容`：先给定义/规则，再给最小例子；每段只讲一个语义单元。
3. `## 实际应用` 只在主题真实需要时出现；例子必须可执行或可复算。
4. `## 常见误区` 至少 2 条，写「现象 → 为什么误导 → 正确判断标准」。
5. `## 总结与思考题`：2-3 个问题，考刚建立的判断而非复述。
6. 现实世界事实没有可靠来源时，写进 `## 待核实信息` 并标注，禁止伪装成确定结论。

## 语言纪律

- 面向指定学段调整词汇密度，但不牺牲准确性。
- 每句话先结论后依据；删除「值得注意的是」「简单来说」等填充语。
- 目标长度服从调用方给的字数区间；宁可精炼不可注水。

## 用户要求优先级

调用方传入的明确要求（对比表、计划、题目、材料形式）必须落实为独立小节，
不得只在大纲里提一句。
