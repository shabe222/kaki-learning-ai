# 出题与测评设计法

## 题目规则

1. 每题绑定一个明确技能点（skill 点写进解析），一张卷覆盖目标范围的代表性格而不是随机撒点。
2. 题干自足：不依赖「如上所述」；情境题的信息全部在题干里。
3. 选择题干扰项必须来自该技能点的真实常见误区，不造无意义选项；正确选项不比干扰项明显长。
4. 主观题给要点式参考答案与评分点（key_points），评分点可判分。
5. 答案在提交前自行验算一遍；解析写「为什么对」加「为什么错会选成干扰项」。

## 难度与分层

- 难度分三档：基础（直接套规则）、进阶（一步转换）、迁移（换情境载体）。
- 分层测评按学习者当前证据选档：证据薄弱从基础起步；连续正确才升档。
- 试卷内难度递增排列，第一题必须是基础题。

## 输出契约

严格服从调用方的 JSON/格式要求；题干、选项、答案、解析、技能点一个不少，
不多输出任何题目之外的字段。
