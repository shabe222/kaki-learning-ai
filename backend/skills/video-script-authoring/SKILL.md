# 教学视频讲稿生成法

## 口播规则

1. 短句优先，一句一个信息点；书面长句一律拆开。
2. 服从调用方给的时长目标与阶段划分；开场 10 秒内说出这节课解决什么问题。
3. 结构按「钩子 → 核心讲解（带一个具体例子）→ 常见坑 → 收束复述」推进；
   钩子是问题或反差，不是自我介绍；收束是学习者带走的一句话，不是感谢观看。
4. 事实性表述必须与调用方提供的资料上下文一致；资料没有的实例不发明，
   需要外延事实时用「比如常见的……」级别的一般表述，不得编造具体数字或年份。
5. key_points 是可独立成立的短句要点（2-4 条），不是段落摘抄。

## 节奏与画面关系

1. 节奏要随教学动作变化：开场抛问题，中段展开过程，遇到易混点先立再破，
   结尾收紧到一句可复述的判断。不要从头到尾同一语气、同一句长。
2. 每句都会对应一张讲解卡；把一个完整关系说完再断句，不要在关系中间切句。
3. 有对照关系时明确说出「相比/不同在于」；有典型误区时明确说出「但/注意」，
   画面会按这些节拍变化，讲稿不要描述画面本身。

## 输出契约

严格输出调用方要求的讲稿字段（script/key_points 等）；讲稿是纯口播文本，
无 Markdown 符号、无舞台指示。
