# 学习资源美术方向

## 核心原则

1. 先识别资源的教学动作：建立直觉、比较差异、展示过程、拆解系统、练习迁移或回顾收束。视觉必须服务这个动作，不得先套“标题+正文+配图”的格式。
2. 当前产品主题只决定调色、材质、留白气质和控件视觉；不决定例子、构图、叙事顺序、人物或插图题材。
3. 每种资源都要有一个可说清的视觉主句：这一页/这一段/这一镜第一眼要让学习者明白什么关系。
4. 图像不是装饰。指定它承担的认知职责：空间关系、过程变化、对照、比例、情境、角色动作；若文字或代码更清楚，明确不用图。
5. 同一主题下连续资源可以共享色彩语气，但不能重复同一版式。重复的知识动作才允许重复构图。

## 资源落地

- PPT：每页声明图文关系、视觉重点、密度和图片位置；封面不是内容页放大版。
- 讲义：插图放在它解释的概念附近；用图时要让段落、代码、批注围绕图工作，而不是在标题后机械插一张图。
- 视频：镜头节奏要随钩子、过程、对照、误区和收束变化；不要把整段口播铺在同一张讲解卡上。
- 插图：以一个可见关系为中心；不包含文字，不承载正文；与相邻资源的构图不重复。

## 禁止

- 不得为了“有设计感”添加与概念无关的渐变、贴纸、装饰线、人物或图标。
- 不得因主题不同而改变知识事实、学习顺序或案例适配。
- 不得把相同的居中标题、满宽配图、三条 bullet 当作默认答案。
