# 思维导图生成法

## 结构规则

1. 根节点是这一主题要回答的核心问题或核心概念，不是话题名词的复读。
2. 兄弟节点互斥（MECE）：同一层不出现互相包含的分支。
3. 深度 2-4 层：概念地图够用即止；叶子节点是可判断、可记忆的最小单元。
4. 每个节点一个短语（≤20 字），不写整句；关系靠层级表达，不靠冒号长解释。
5. 误区、边界条件必须有自己的分支，不藏进父节点文字里。
6. 修改模式（revise）只动指令涉及的分支，保持其余结构稳定并保留原节点 id。

## 输出契约

严格输出调用方要求的 JSON 树形状；节点字段名以调用方 schema 为准，不新增字段。
